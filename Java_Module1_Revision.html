WORA. javac compiles source code into bytecode (a .class file). The JVM on each platform then interprets or JIT-compiles that same bytecode into native instructions, so one compiled program runs on any operating system.
Trick question. Bytecode is platform independent, but the JVM is platform dependent. Do not write that "the JVM is platform independent".

Abstraction

Abstraction. Hiding the internal implementation details and showing only the essential features to the user. It manages complexity through hierarchical classification: you drive a car as one object without thinking about the thousands of parts inside it.

How it helps manage complexity:

  1. Hides unnecessary detail, so the user works with a simple interface.
  2. Breaks a large system into levels. A car is made of engine, transmission and brakes, and the engine is made of its own parts. Each level is understood on its own.
  3. Reduces errors, because outside code cannot misuse hidden internals.
  4. Eases maintenance, because the implementation can change without affecting the code that uses it.
  5. In Java it is achieved with classes, abstract classes and interfaces (Module 3). Example: Math.sqrt(25) gives the result without showing the algorithm.

The three OOP principles

Encapsulation. Binds code and the data it manipulates into one unit (the class) and keeps both safe from outside interference and misuse. Data is usually private and reached only through public methods, so the class acts as a black box.
Inheritance. The process by which one class acquires the properties and behaviour of another. It supports hierarchical classification and code reuse. The existing class is the superclass, and the new class is the subclass, written with extends.
Polymorphism. "One interface, multiple methods." The same method name performs different actions depending on context. Compile-time polymorphism is method overloading. Run-time polymorphism is method overriding.

Using blocks of code

Block. Statements enclosed in { } treated as one unit. Used for method bodies, loop bodies and if bodies. A variable declared inside a block is local to it.

Class and object

Class. A template (blueprint) that defines the data (fields) and the code (methods) that operate on that data. A class defines a new data type. An object is an instance of a class. A class is a logical construct, and an object is its physical existence in memory.

Lexical Issues

A Java program is made of whitespace, identifiers, literals, comments, operators, separators and keywords.

Whitespace

Java is a free-form language, so there are no indentation rules. Whitespace means a space, tab, newline or form feed. At least one whitespace character is needed between two tokens that are not already separated by an operator or separator.

Identifiers

Identifier. The name given to a class, method, variable, interface and so on.

Rules: letters, digits, underscore and dollar sign only. It must not begin with a digit, it is case-sensitive, it cannot be a keyword, and it cannot contain spaces or symbols such as - or @.

Primitive Types

Java is strongly typed: every variable and expression has a type, and the compiler checks compatibility. There are 8 primitive types in four groups. Everything else (arrays, strings, classes) is a reference type.

Range formula

Signed integer with n bits: range is -2^(n-1) to 2^(n-1) - 1. One bit is the sign, so the negative side goes one further. The unsigned char uses 0 to 2^n - 1.
TypeBitsCalculationRange
byte8-2^7 to 2^7 - 1-128 to 127
short16-2^15 to 2^15 - 1-32,768 to 32,767
int32-2^31 to 2^31 - 1-2,147,483,648 to 2,147,483,647
long64-2^63 to 2^63 - 1-9,223,372,036,854,775,808 to 9,223,372,036,854,775,807
char160 to 2^16 - 10 to 65,535 (unsigned)

Integers: byte, short, int, long

  • All are signed. Java has no unsigned keyword. Negative numbers are stored in two's complement.
  • byte: smallest. Used for raw binary data and file or network streams.
  • short: rarely used.
  • int: the most common. Integer literals are int by default. Used for loop counters and array indexes.
  • long: for very large values. Literals need the L suffix.

Variables, Scope and Lifetime

Variable. The basic unit of storage in Java: a named memory location with a type, whose value can change while the program runs.

A local variable must be assigned a value before it is read, or the program does not compile. Unlike C, Java never lets you read an uninitialized local.

Dynamic initialization

Dynamic initialization. Initializing a variable with an expression that is evaluated at run time, not just with a constant.

Scope

Scope. The region of the program where a variable is visible and usable. A block defines a scope. The two main kinds are class scope and method scope.
  1. An inner block can access variables of the outer block.
  2. An outer block cannot access variables declared in an inner block.
  3. Java does not allow an inner-block variable to have the same name as one in an enclosing scope. C and C++ allow this (shadowing). Java does not.

Lifetime

Lifetime. How long a variable exists in memory. A local variable is created when execution enters its scope and destroyed when it leaves, and its value is lost. A variable declared inside a loop is re-created and re-initialized on every iteration.

Automatic conversion (widening)

Automatic type conversion. Java converts a value to another type automatically when (1) the two types are compatible, and (2) the destination type is larger than the source type.

  • Numeric types are compatible with each other. Numeric types are not compatible with char or boolean, and those two are not compatible with each other.
  • A literal that fits is assigned without a cast: byte b = 10;

Casting (narrowing)

Casting. Forcing a conversion when the destination is smaller than the source, or the types are not automatically compatible. Form: (target-type) value
  • Floating-point to integer: the fractional part is truncated, not rounded. (int) 9.7 is 9.
  • Integer to a smaller integer: the value is reduced modulo the target's range. (byte) 257 is 1.

Automatic type promotion in expressions

Promotion rules.
  1. All byte, short and char operands are promoted to int.
  2. If any operand is long, the whole expression is long.
  3. If any operand is float, the whole expression is float.
  4. If any operand is double, the result is double.

Arrays

Array. A group of like-typed variables referred to by a common name. Elements are reached by an index that starts at 0. Arrays in Java are objects stored on the heap.

One-dimensional arrays

  • Default values after new: numeric elements are 0, boolean is false, char is '\u0000', references are null.
  • Bounds are checked. Using arr[5] on a 5-element array throws ArrayIndexOutOfBoundsException at run time. C gives no such protection.
  • The size is arr.length: a field, no parentheses. A String's size is s.length(), a method. This is a classic trap question.

Assignment operator

var = expression; can be chained: x = y = z = 100; is evaluated right to left. The compound forms (+=, *= and so on) are also assignment operators.

The ? operator (ternary)

Form: expression1 ? expression2 : expression3. If expression1 (which must be boolean) is true, the result is expression2. Otherwise it is expression3.

Points to remember

  • The condition must be boolean. if (x = 5) is a compile error.
  • Without braces only the next single statement belongs to the if. Use braces whenever there is more than one.
  • An else belongs to the nearest unmatched if (dangling else).
  • switch accepts byte, short, int, char, String, enum and their wrappers. Not long, float, double or boolean.
  • Case labels must be constants or literals, and duplicates are an error.
  • switch tests only equality. It cannot test ranges such as marks >= 90.
  • default is optional, normally last. A missing break causes fall-through, the most-asked trick question.

Iteration Statements

Iteration statements repeat a set of statements as long as a condition remains true. Each pass through the body is one iteration. A loop has four parts: initialization, condition, body and update.
TypeKey feature
whileEntry-controlled. The condition is checked before the body, so the body may run zero times.
do-whileExit-controlled. The condition is checked after the body, so the body runs at least once.
forInitialization, condition and update on one line. Best when the count is known.
for-eachA read-only walk through every element of an array or collection, with no index.
nested loopsA loop inside a loop: rows and columns, patterns, matrices.
Local variable type inference. Using var instead of writing the type, so the compiler infers it from the initial value (Java 10 and later). Example: for (var i = 0; i < 5; i++). It needs an initializer. It is not dynamic typing, because the type is fixed at compile time.

Jump Statements

Jump statements transfer control unconditionally to another part of the program.
break. Has three uses: (1) terminates a statement sequence in a switch, (2) exits a loop, (3) acts as a "civilized goto" through a labeled break.
continue. Skips the rest of the current iteration and moves to the next one. In a for loop control goes to the update expression, then the condition. It can also be labeled.
return. Exits the current method and passes control back to the caller. It returns a value (return n * n;) or nothing (return; in a void method).

Points to remember

  • Label syntax: labelName: goes directly before the loop, then break labelName; or continue labelName;.
  • A labeled break needs a label that encloses the statement. You cannot jump to a label elsewhere, which is why it is "civilized" compared with goto.
  • goto is reserved but not usable in Java.
  • continue outside a loop, or break outside a loop or switch, is a compile error.
  • In a while loop, do the update before continue, or the loop never ends.
